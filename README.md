# Автоматизация тестирования интернет-магазина Demo Web Shop

## Описание проекта

Данный проект разработан в рамках дипломной работы по курсу **Автоматизированное тестирование на Python**.  
В качестве объекта тестирования выбран демонстрационный интернет-магазин **Demo Web Shop** (https://demowebshop.tricentis.com/), работающий на платформе nopCommerce.

Цель проекта – создание набора автоматизированных тестов, покрывающих ключевые пользовательские сценарии, с применением современных подходов к разработке тестовых фреймворков.

## Используемые технологии

- **Python 3.13+**
- **pytest** – фреймворк для запуска тестов
- **Playwright** – инструмент для автоматизации браузеров
- **Page Object Model (POM)** – архитектурный паттерн для организации кода
- **Allure** – система репортинга и визуализации результатов тестов
- **Docker** (опционально) – контейнеризация для воспроизводимого запуска
- **Git** – система контроля версий

## Требования к окружению

Для работы с проектом необходимо установить:

- Python 3.13 или выше
- pip (менеджер пакетов Python)
- Playwright и браузеры (Chromium, Firefox, WebKit)
- Allure командной строки (для генерации отчётов)
